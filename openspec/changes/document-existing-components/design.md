# Design

## Decision

The coverage map names a file and one or more existing requirement headings. The check reads canonical specs and this pending change. It does not edit archived change folders.

Notes remain an account route because their tests and the notes spec already exist. They are not a primary workbench destination.

Storybook stays the component catalog. Its pages link to requirement ids. Publishing it next to the docs site is documented and is not enabled.

## Not in this change

- No comparison or hierarchy implementation.
- No change to an archived spec hash.
- No GitHub review record.
