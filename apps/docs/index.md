# Agent App Template

A public template for internal applications. The sample is a signed-in Hello world page with a real session and a real database. It does not contain business data.

The docs site is configured for GitHub project Pages at `/agent-app-template/`. That site is not live until a human sets Pages to deploy from GitHub Actions and the default branch workflow runs. Nothing in this repository has been deployed.

Start with [Bootstrap](./guide/bootstrap).
